# ADR-0004: Architecture Governance with ADRs and RFCs

- **Status:** Accepted
- **Date:** 2026-07-12

## Decision

Project Brain Engine uses two governance mechanisms:

- **ADR** for accepted architectural decisions;
- **RFC** for unresolved proposals that require discussion, experimentation, or validation.

An accepted ADR may only be replaced by a newer ADR that explicitly supersedes it.

## Rationale

Not every promising idea should become an architectural constraint immediately.
